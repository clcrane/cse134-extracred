# Aesthetic Statement

The aesthetic I chose for my personal website is Earth Tones:
https://aesthetics.fandom.com/wiki/Earth_Tones

I chose Earth Tones because I wanted my portfolio to feel warm, calm, and natural instead of overly bright or technical. I used colors like cream, brown, sage green, sand, and terracotta throughout the page. I also used softer borders, rounded corners, and subtle shadows to make the sections feel more welcoming. The colors are stored as CSS custom properties so the overall design stays consistent.

For my JavaScript enhancement, I added a theme toggle that allows the user to switch between the Earth Tone theme and a lighter theme. The JavaScript uses the addEventListener to change the theme when the button is clicked.

One usability and accessibility choice I made was keeping visible focus outlines on navigation links and buttons so someone using a keyboard can tell which element is selected. I also added responsive CSS so the navigation and page layout work on smaller screens without requiring horizontal scrolling.

Marshall McLuhan's idea that "the medium is the message" connects to this website because the way the portfolio is presented affects how someone understands me before they even read all of the content. The Earth Tone colors and calmer design create a different impression than a plain or extremely detailed website would. Since a personal website is something I can fully control, the design itself becomes part of how I represent myself. The code, layout, colors, and interactions help communicate the type of experience I want someone to have while looking through my portfolio.
